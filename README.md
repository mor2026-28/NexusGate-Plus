# NexusGate Plus · 枢门集群版 (v1.0.7)

**NexusGate Plus (v1.0.7)** 是在 NexusGate v5.1 基础上全面重构升级的 **「一主控统管多中转 + 共享落地池 + 3x-ui 多机无损归并 + 秒级热备容灾」** 分布式节点编排与分流主控系统。底层唯一采用极致轻量的 **Sing-box** 核心，零第三方 npm 依赖（纯 Node.js 原生标准库驱动），主控常驻内存 **~25 MB**，受控端 Agent 常驻内存 **< 15 MB**。

---

## 核心架构亮点（彻底解决多机中转与落地运维痛点）

### 1. 一台主控统管全部「多域名中转机 + 无域名共享落地机」
- **多中转机独立域名 (`Relay Node`)**：每台中转机可绑定各自的专属入口域名（如 `hk1.domain.com`、`jp1.domain.com`、`sg1.domain.com`）与独立 SSL 证书。在主控面板创建或管理节点时，订阅与分享链接自动匹配对应中转机的专属域名，无需再开几十个浏览器标签页逐台登录面板。
- **落地机一键建站与全局共享池 (`Shared Exit SS Pool`)**：落地机无需绑定域名（纯 IP），只需执行一行 Agent 安装指令并在主控将其角色设为 **「纯落地机 (Exit)」**，主控即自动在落地机上拉起高性能 Shadowsocks / SS-2022 节点，并自动注册进主控的 **全局共享落地出站池**，供所有中转机的任意客户节点一键勾选转发（一对一或一对多共享落地）。
- **控制面与数据面解耦（离线自治）**：即使主控面板重启或网络维护，所有中转机与落地机上的 `sing-box` 凭本地已同步的配置文件与证书 100% 正常转发流量，绝不影响客户连接。

### 2. 多台 3x-ui / X-Panel 面板数据「零断流、无损合并迁移」
- **多机分域归并导入**：在「备份迁移」页面选择某台中转机（或自动新建中转机），上传该机原本的 `x-ui.db` 或 `3xui_backup.tar.gz`，完整保留原 UUID、密码、端口、Reality 密钥对、WS/gRPC 路径、SNI、客户已用流量、到期时间、IP/设备数限制及 `/root/cert` 证书。
- **跨机同端口防冲突与共享落地自动去重**：
  - 即使多台旧 3x-ui 机器上都有相同端口（如 443、8443）或相同 `inbound-443` 标签，主控按中转机维度自动做命名空间隔离，绝不互相覆盖；
  - 若多台 3x-ui 中转机指向同一台落地 SS 节点（相同 `IP:Port`），系统自动识别并去重合并为同一个 **全局共享落地出站**，后续一处修改落地密码或 IP，所有关联中转机自动同步生效。

### 3. 主力中转机故障「秒级热备接管 + Cloudflare DNS 自动改绑 IP」
- **告别“重装 3x-ui + 导备份”**：传统方案中，主力中转机故障后需要新买机器、重装 3x-ui、再找备份导入；在 **NexusGate Plus** 中，节点数据与证书全部保存在主控，并支持开启 **「实时热备镜像预热 (`Mirror Standby`)」**——平时主控自动将主力中转机的配置与证书实时同步至备用机预热。
- **3 秒完成容灾漂移**：当主力中转机故障时，在主控面板点击 **「⚡ 一键容灾切换」**（或开启自动容灾），热备机毫秒级接管所有相同端口与 SSL 证书，同时主控通过 **Cloudflare DNS API** 自动将该中转机域名的 A/AAAA 解析记录秒级切换至备用机 IP（TTL 60s），客户无需更新订阅、零感知恢复连接！主力机修好后点击 **「✓ 一键回切」** 即可平滑切回。

## 一键安装命令

### 1. 主控面板机 (Master Panel) 安装

在 Debian / Ubuntu / CentOS / AlmaLinux / Rocky / Alpine 服务器上以 `root` 权限执行：

```bash
bash <(curl -Ls https://raw.githubusercontent.com/mor2026-28/NexusGate-Plus/main/install.sh)
```

### 2. 受控端 (中转机 / 落地机 / 热备容灾机 Agent) 一键接入

在主控面板「中转与落地集群」页面点击 **「＋ 添加服务器」** 后，直接点击卡片上的 **「📋 复制 Agent 安装命令」** 在目标机器执行即可：

```bash
curl -fsSL https://raw.githubusercontent.com/mor2026-28/NexusGate-Plus/main/scripts/install-agent.sh | bash -s -- \
  --master "https://你的主控地址:端口/安全路径" \
  --node-id "node_xxxx" \
  --token "ag_xxxxxxxxxxxx" \
  --port "19090"
```

> **提示（原 3x-ui 机器原地平滑接管）**：如果你刚在主控导入了某台中转机的 `x-ui.db` 备份，只需在上面的 Agent 安装命令末尾加上 `--takeover-3xui`，脚本会自动停止旧 `x-ui` 释放端口，并由 `sing-box` 在 1 秒内接管全部端口与证书，客户完全无感知！
